## Project Overview

Squirrel Coffee is a compiler for a simplified Java-like programming language. It compiles source code (.java files) to JVM bytecode using a multi-pass architecture with Jasmin assembler integration.

## Development Commands

### Build
- `make all` or `make tjc` - Build the compiler executable
- `make clean` - Clean build artifacts (object files, generated parser/lexer files)
- Alternative: `cmake . && make` for CMake-based build

### Run Compiler
- `./tjc <input_file>.java` - Compile Squirrel Coffee source to bytecode
- Generates `.jsm` (Jasmin assembly) and `.class` (JVM bytecode) files

### Testing
- Test with provided samples: `./tjc Sample1.java` or `./tjc Sample2.java`
- Verify generated bytecode with: `java <ClassName>` (after compilation)

## Architecture Overview

The compiler follows a classic multi-pass architecture:

1. **Lexical Analysis** (tjc.l) → **Parsing** (tjc.y) → **AST Generation**
2. **Symbol Table Construction** (SymbolTable.cpp) - First AST traversal
3. **Semantic Analysis** (SemanticCheck.cpp) - Type checking and validation
4. **Code Generation** (CodeGenerator.cpp) - Jasmin assembly generation
5. **Assembly** - Jasmin assembler produces final .class files

### Key Components

- **AST Framework** (ast/): Comprehensive node hierarchy with visitor pattern support
  - Declaration nodes: ClassDeclaration, MethodDeclaration, VariableDeclaration
  - Expression nodes: BinaryExpression, UnaryExpression, LiteralExpression
  - Statement nodes: IfStatement, WhileStatement, BlockStatement

- **Visitor Pattern**: Three main visitors process the AST sequentially:
  - SymbolTable: Builds symbol table with scope information
  - SemanticCheck: Performs type checking and semantic validation
  - CodeGenerator: Generates Jasmin assembly code

- **Symbol Table System**: Hierarchical entries (Entry.h → Variable, Field, Method, Class, Package)
  - Manages scoping at package, class, and method levels
  - Tracks variable declarations and method signatures

## Language Constraints

- Single public class per file (same name as filename)
- All methods must be static
- No access modifiers except public for main class
- No package/import statements (default package only)
- Built-in SimpleIO class for console I/O operations

## Important Notes

- **Jasmin Dependency**: Uses bundled Jasmin 2.4 assembler (jasmin-2.4/)
- **Hardcoded Path**: Makefile may contain workspace-specific paths that need updating
- **Type System**: Supports int, float, String with automatic conversions
- **Entry Point**: Main method must be `public static void main(String[] args)`
